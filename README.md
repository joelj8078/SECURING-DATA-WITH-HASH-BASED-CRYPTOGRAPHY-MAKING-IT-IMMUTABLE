# SECURING-DATA-WITH-HASH-BASED-CRYPTOGRAPHY-MAKING-IT-IMMUTABLE
The project, titled "Securing Data with Hash-Based Cryptography, Making it Immutable," addresses the evolving threat posed by quantum computers to traditional cryptographic systems. With the advancement of quantum computing, algorithms such as RSA and ECDSA, which are currently widely used for securing data, are becoming vulnerable to quantum attacks. To mitigate this risk, the project implements SPHINCS (Stateless Practical Hash-based Signature), a post-quantum cryptographic algorithm, to provide robust, quantum-resistant data authentication.
SPHINCS, a hash-based signature scheme, is designed to remain secure even in the face of quantum threats. Unlike traditional public-key cryptosystems, SPHINCS does not rely on hard mathematical problems that can be efficiently solved by quantum computers. Instead, it uses a stateless approach to generate digital signatures by hashing messages in a manner that is resistant to quantum algorithms like Shor’s algorithm. This ensures long-term security and data integrity.
In the context of this project, the SPHINCS algorithm is integrated into a server-client authentication system where users generate a public-private key pair and perform secure login procedures through digital signatures. The system ensures that user credentials are verified without the need to send sensitive information like passwords, making it both secure and quantum-resistant. The project thus demonstrates the practical use of SPHINCS in securing communication in the era of quantum computing, offering a reliable alternative to traditional cryptographic schemes.
